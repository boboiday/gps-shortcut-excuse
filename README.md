The GPS's own excuse, in its own voice, for sending the driver down the wrong road — late to his own wedding via the scenic route. Entry for the make.fun bounty "The GPS Swears It Was a Shortcut".

## Run it

```sh
node main.ts
```

Prints the one-line excuse (164 characters) and writes it to `/output/entry.txt`.
